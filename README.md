Bu proje, OpenCV ve yapay zeka teknolojileri kullanılarak geliştirilmiş bir araba satış web sitesidir. Sistem, kullanıcıların araçları çeşitli kriterlere göre karşılaştırmasına, değerlendirmesine ve yapay zekanın analizine göre en uygun aracı seçmesine olanak tanır. Fiyat, kilometre, yakıt türü, model yılı gibi veriler üzerinden yapılan analizlerle, kullanıcıya özel araç önerileri sunulmaktadır.

Ayrıca web sitesine giriş kısmı güvenli hale getirilmiştir. OpenCV kullanılarak yüz tanıma sistemi entegre edilmiş ve böylece yalnızca tanımlı kullanıcıların siteye giriş yapması sağlanmıştır. Bu sayede hem kullanıcı güvenliği artırılmış hem de modern biyometrik doğrulama teknolojileri kullanılmıştır.

Projenin arayüzü kullanıcı dostu olarak tasarlanmış, arka planda ise Python dili ile geliştirilen yapay zeka algoritmaları ve görüntü işleme teknikleri bir arada çalıştırılmıştır. Web tarafında Flask kullanılmıştır.
